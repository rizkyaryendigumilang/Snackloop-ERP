Pasang SnackLoop ERP

Akses instan dari Layar Utama HP / Laptop tanpa buka browser. Bekerja offline!

Pasang SnackLoop ke Layar Utama

Akses cepat 1-klik & bekerja offline

Panduan pasang di HP Android via Google Chrome atau Samsung Internet:

1
Ketuk tombol Menu Titik Tiga (⋮) di pojok kanan atas browser.
2
Pilih opsi "Pasang Aplikasi" atau "Tambahkan ke Layar Utama".
3
Ketuk Install / Pasang. Ikon SnackLoop akan otomatis muncul di home screen Anda!

Panduan pasang di iPhone / iPad via browser Safari:

1
Ketuk tombol Bagikan (Share) di bar bawah Safari:
Ikon Share
2
Gulir ke bawah dan ketuk "Tambahkan ke Layar Utama" (Add to Home Screen).
3
Ketuk Tambah (Add) di pojok kanan atas.

Panduan pasang di Windows / Mac via Google Chrome atau Microsoft Edge:

1
Lihat ke Bilah Alamat URL (Omnibar) di bagian kanan atas browser Anda.
2
Klik ikon Pasang / Komputer (Install app) atau ikon panah ke bawah.
3
Klik tombol Install. SnackLoop akan terbuka di jendela mandiri layaknya software desktop!
